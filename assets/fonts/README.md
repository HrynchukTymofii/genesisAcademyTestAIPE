# Fonts

The PDF report needs a TrueType font with Cyrillic/Greek coverage. By default it uses
**DejaVu Sans** (`DejaVuSans.ttf`, `DejaVuSans-Bold.ttf`) from matplotlib's bundled
copy (`matplotlib/mpl-data/fonts/ttf/`), so nothing extra is shipped.

To use another font, place files with those exact names in this directory; they take
precedence. DejaVu fonts are free to redistribute (Bitstream Vera / DejaVu license).
